Student portfolio

Aslah Ghazali’s Digital Humanities Portfolio

Portfolio introduction. Across these projects, I explore how digital methods can help us read language, literature and culture more closely. I have worked with Malayalam words in Manglish, literary references to Indian plants and animals, spelling rules, and patterns in a short story. Each project begins with a practical question and asks what its evidence can support. I use code and language models to organise material, then check their results against the source texts and the limits of each method. The exhibitions below share the work, the findings and the questions that remain.

Assignment 01

Malayalam Stopwords: Malayalam Stop Words in Manglish

Abstract. This project asks how a practical list of Malayalam stop words can support text processing when the words are written in Manglish, or Roman script. It brings together common function words in a Python set for use in basic text-cleaning work. The project presents the list as a starting resource rather than a complete or formally validated lexicon. Its examples also show why spelling variation and context matter: filtering a word mechanically can remove meaning as well as noise.

View the GitHub repository · Visit the project website

Visible assignment work

The exhibition shows Manglish examples, a simple preprocessing map and notes on coverage, tokenisation and spelling variation. It explains how the list can be applied and where its limits should guide a reader.

Assignment 02

RAG Flora and Fauna

Abstract. This study asks whether a small language model using retrieval-augmented generation can identify plants and animals named in Indian literary texts. Eight works were queried with Gemma 3 4B through AnythingLLM and LM Studio; after an initial prompt performed poorly, a source-specific prompt was used across the corpus. Of 106 model-generated entries, only 19 were fully correct, while many quotations could not be found in the books. A separate, text-checked inventory records 509 entries, including 469 verified names and 40 ambiguous cases. The gap between the two lists points to limited retrieval, model and prompt bias, colonial translation choices, and categories that do not fit every cultural reference.

View the GitHub repository · Visit the project website

Visible assignment work

The exhibition compares the model’s suggestions with a verified, quotation-based inventory. It also follows the sources of error, from missing passages and invented quotations to category mistakes and culturally specific plant names.

Assignment 03

Spelling Checker Skill

Abstract. This project builds a small writing assistant for spelling checks. It can flag likely errors, return a corrected version, explain changes, or follow a requested British or American spelling convention. British English is the default. The skill aims to preserve a writer’s meaning, tone and sentence structure, and to flag uncertain names or specialist terms rather than silently changing them. Its narrow remit makes clear where automated correction can help and where a writer’s judgement remains necessary.

View the GitHub repository · Visit the project website

Visible assignment work

The page presents the skill’s commands, a short correction example and a five-step workflow, from reading the request to returning the checked text. Its examples show how the tool keeps the writer’s phrasing intact.

Assignment 04

Synthetic Reading: The Necklace

Abstract. This project uses language-model-assisted phrase analysis to examine how Guy de Maupassant’s “The Necklace” links social aspiration, appearance, money and mistaken ideas of value. The story is divided into 13 researcher-defined segments and four narrative stages; extracted phrases are checked against the text and grouped under four interpretive dimensions. The counts show a movement from Mathilde’s longing and the ball to loss, debt and the final revelation about the imitation necklace. They support a close reading of the story, while remaining descriptive: phrase counts alone cannot establish literary meaning.

View the GitHub repository · Visit the project website

Visible assignment work

The project presents four stages of the story, its phrase categories and interactive visualisations, including patterns by segment and theme. A report sets out the research question, method, counts and interpretive limits.

02

Portfolio reflection

Across the portfolio, I have learned that a digital method is only as useful as the evidence behind it. A word list needs clear limits, a model’s extracted names need to be checked against the books, and phrase counts need to be read alongside the story. These projects also show that tools shape what becomes visible: prompts, categories and spelling choices all affect the result. Presenting the work online makes the methods and their uncertainties easier to inspect, and gives readers a route from summary to source.

Methods note

I used Python for the Malayalam word list and for organising textual data, retrieval-augmented generation for candidate plant and animal references, and a language-model skill for spelling checks. For the literary analysis, phrases were extracted, checked against the story and counted within researcher-defined segments. I report uncertain or unverified results as such, distinguish model suggestions from text-checked evidence, and link to the project pages and reports so readers can examine the work in context.
